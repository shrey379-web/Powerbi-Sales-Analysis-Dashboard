# 📊 Power BI Project: Sales Analysis Dashboard

Excited to share another hands-on Power BI project — **Sales Analysis Dashboard!** 🚀

This dashboard provides a detailed breakdown of sales trends across different states, cities, products, and quantities, enabling data-driven business decisions and performance tracking.

---

## 📌 Dashboard Highlights

- 🏙️ City-wise sales breakdown across Bhopal, Pune, Hyderabad, Bengaluru, and Mathura  
- 🧑‍🤝‍🧑 Performance analysis by sales representatives like Gopal, Adwait, and Chitra  
- 💰 Sum of Selling Price and Product Cost visualized by Order ID and Quantity  
- 📈 Trend analysis via pie charts, line graphs, bar graphs, and dynamic filters  
- 🎯 KPIs such as Total Products (10), Total Quantity (100), and Selling Price (₹34K) for easy monitoring  

---
